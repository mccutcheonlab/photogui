# photogui-webapp

Dash webapp version of photogui, structured using lickcalc as a template.

## Structure
- `app.py`: Main Dash app entry point
- `assets/`: Static files (CSS, favicon, help HTML)
- `callbacks/`: Dash callback modules
- `data/`: Example and test data
- `docs/`: Documentation
- `notebooks/`: Jupyter notebooks
- `paper/`: Publication files
- `templates/`: HTML templates
- `tests/`: Test files
- `utils/`: Utility functions

## Setup
See `requirements.txt` for dependencies.
